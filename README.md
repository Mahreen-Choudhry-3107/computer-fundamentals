## 📖 About

This repository is a **structured collection of computer science fundamentals** — the core concepts every software engineer needs, whether you're preparing for interviews, revising for exams, or building a strong foundation from scratch.

Each topic lives in its own Markdown file, written to be **concise, example-driven, and interview-focused** — with tables, diagrams, code snippets, and revision questions at the end of every note.

> 🎯 **Goal:** Go from fundamentals to interview-ready, one topic at a time.
